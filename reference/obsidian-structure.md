The structure of the Obsidian vault described in the sources is designed to be a **minimalist, "bullshit-free" Zettelkasten system** that focuses on the writing process rather than complex plugins. The system uses six primary folders to organize knowledge, moving from temporary thoughts to permanent, connected insights.

Below is the detailed structure of these sections as maintained in the system:

### 1. Rough Notes
This is the first folder in the hierarchy and acts as a **temporary staging area** or digital notepad.
*   **Purpose:** To jot down anything temporary, such as immediate ideas, reminders, or rough thoughts that the user doesn't want to forget.
*   **Usage:** It can be used for tracking habits (like daily word counts) or keeping lists of ideas for future research.
*   **Maintenance:** The author notes that this folder is not used heavily if one prefers to keep rough ideas on paper, making it an optional but helpful buffer for digital-first users.

### 2. Source Material
This folder stores insights derived from external content.
*   **Contents:** Notes on books, videos, articles, podcasts, or even Twitter threads.
*   **Organization:** It often contains **subfolders** categorized by the type of media (e.g., Books, Articles).
*   **Active vs. Archived:** Notes that are currently being worked on are left "unsorted" at the bottom of the folder. Once the writing process for that source is complete, the note is moved into its respective subfolder.
*   **Note Structure:** These notes include the source title, page numbers (if applicable), relevant quotes, and—most importantly—an **expansion of the ideas in the user's own words** to ensure active learning.

### 3. Tags
Unlike traditional hashtag systems, this setup treats tags as **empty notes** stored in a dedicated folder.
*   **Method:** To "tag" a note, the user creates a link to a tag note using double square brackets (e.g., `[[Humility]]`).
*   **Storage:** These tag notes are kept in the "Tags" folder to prevent them from cluttering the main notes folder.
*   **Philosophy:** Tags should be based on **personal interests** rather than broad, vague categories. For example, instead of just "Self-improvement," a user might use a specific tag like "Dangers to male-female relationships".
*   **Constraint:** It is recommended to keep the number of tags per note between one and five to avoid messiness.

### 4. Templates
The templates folder stores the standardized structure for all "Main Notes" to ensure consistency and speed.
*   **Workflow:** Using the "Templates" core plugin and a hotkey (like `Ctrl+T`), the user can instantly apply a structure to a new blank note.
*   **Structure of the Template:**
    *   **Metadata:** Automatically populated date and time.
    *   **Status:** A tag indicating the development stage of the note (e.g., `#baby`, `#child`, or `#adult`).
    *   **Title:** A large, bold heading using a hashtag.
    *   **Body:** Ample blank space for the "Mini-essay".
    *   **Reference Section:** A dedicated area at the bottom to link back to the Source Material or other related notes.

### 5. Indexes
Indexes are an evolved form of tags used to navigate the network once it becomes large and complex.
*   **Evolution:** When a specific tag note accumulates a large number of links (e.g., 50+ notes), it is turned into an **Index**.
*   **Structure:** The previously empty tag note is filled with **subheadings and organized links** to the relevant notes.
*   **Function:** It acts as a "Table of Contents" or a clear entry point for a specific area of study, transforming a "spider web" of notes into a logical structure.

### 6. Main Notes
Often called "Atomic Notes" or the "Zettelkasten," this folder is the **"Workhorse"** of the entire system.
*   **Storage:** All permanent notes are stored in this **single folder** without subfolders to maximize flexibility and encourage unexpected connections.
*   **Characteristics:**
    *   **Independent:** They are written to be self-explanatory and independent of the original source.
    *   **Focused:** Each note follows the "one idea per note" rule, usually kept under 500 words and formatted as a "mini-essay".
    *   **Connected:** They heavily utilize hyperlinks to other main notes and the source material to build a "network of knowledge".
